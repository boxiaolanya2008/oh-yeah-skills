# ai-plus-prompt

> [English](README.en.md) | 简体中文

一套面向 LLM 的**中文推理提示词（Prompt）工程**，提供从"单一极限推理协议"到"全场景自适应思考协议"的两个版本，可直接粘贴到任意大模型的系统提示词（System Prompt）中使用。

## 项目结构

```
ai-plus-prompt/
├── README.md        # 中文说明（本文件）
├── README.en.md     # English documentation
├── LICENSE          # MIT License

└── 1.1.5.md         # 协议 V1.1.5：全场景自适应思考协议（当前推荐版本）
```

## 版本区别

| 维度 | V1.1.0（单一强制推理） | V1.1.5（全场景自适应） |
|------|----------------------|----------------------|
| 模式 | 单一模式，所有任务一律走重推理流程 | 双模式：模式 A（常规对话）/ 模式 B（极限推理），按意图隐式切换 |
| 思考呈现 | 必须以 `[阶段一]` 开头，全量输出推导过程 | 四阶段在**内部完成**，输出只保留必要逻辑链 |
| 输出风格 | 强制标题 + 公式 + 短句 | 模式 A 自然对话；模式 B 结构化精简输出 |
| 阶段标签 | 显式输出 | **禁止**输出阶段标签，但逻辑须可还原至各阶段 |
| 回溯机制 | 错误时输出 `[回溯触发]` 字样 | 标记后从最近正确节点重算，不外显 |
| "条件不足"出口 | 需在阶段二证明无解 | 三重条件门槛同时满足才允许使用，防止搪塞偷懒 |
| 篇幅 | 26 行，紧凑 | 66 行，分章节结构化 |

两版共享的**核心推理骨架**（模式 B / V1.1.0 均遵循）：

1. **阶段一**：形式化与极值探测——先转公式/变量，算全局不变量与上下界。
2. **阶段二**：假设树与最小冲突集——候选路径 H1/H2… 各附置信度与推翻条件。
3. **阶段三**：对抗性推演与合规审查——红队找反例，执行字面合规 + 意图合规双重审查。
4. **阶段四**：结构化输出与约束覆盖度自检。

## 哪个版本更好（分场景）

| 使用场景 | 推荐版本 | 原因 |
|----------|----------|------|
| 日常闲聊、情感交流、常识问答 | ✅ **V1.1.5** | 模式 A 自然流畅输出，不会被迫输出假设表和公式堆砌 |
| 创意写作、头脑风暴 | ✅ **V1.1.5** | 模式 A 保留创作自由度，可追问、可调侃 |
| 数学证明、算法 Debug | 🟡 两者皆可 | 都走完整四阶段；V1.1.5 输出更精简，V1.1.0 过程更透明 |
| 竞赛题、硬约束逻辑推演 | 🟡 两者皆可 | 追求逐步可见的推导轨迹选 V1.1.0；追求最终答案质量选 V1.1.5 |
| 需要审查模型完整思考链（教学/调试 Prompt） | ✅ **V1.1.0** | 强制全量输出推导过程，便于逐阶段检查 |
| 长期作为通用 System Prompt | ✅ **V1.1.5** | 双模式自适应，兼顾对话体验与推理深度，适用面最广 |
| 防止模型滥用"条件不足"逃避回答 | ✅ **V1.1.5** | 三重条件门槛显著收紧"无法确定"的出口 |

**总结**：

- **通用场景首选 V1.1.5**——它是唯一能"该闲聊时闲聊、该推理时上强度"的版本，作为默认系统提示词体验最好。
- **纯推理压测/过程审查选 V1.1.0**——它把每一步思考强制外显，适合评测模型推理能力或研究 Prompt 设计。

## 快速开始

1. 复制目标版本文件的全部内容（如 `1.1.5.md`）。
2. 粘贴到模型的 System Prompt（或对话首条消息）中。
3. 正常提问即可——V1.1.5 会自动判定意图并切换模式，无需手动声明。
